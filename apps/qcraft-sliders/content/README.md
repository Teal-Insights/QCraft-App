# content/: the card text for "Q-CRAFT, one input at a time"

`inputs.md` holds the eleven cards the page renders, one section per input, each with the same five headings: What it is, Why it matters, How it enters the model, What the tool does with it, Read more. The reader is a ministry of finance economist who is new to Q-CRAFT: comfortable with debt dynamics, not with this workbook. After reading one card and moving its control, they should be able to say, in their own words, what the input is, which of g, r or pb it moves, and what the tool does mechanically when it changes, and then find the right Guide page to read further. Acceptance test: hand a card to such a reader with the page open, ask them to set the input for their own country and explain the caption's 2099 number to a colleague; they should manage it without opening the Guide, and the Guide pin they cite should be the one in Read more. The page fills `{{country}}`, `{{lastWeoYear}}`, `{{firstLongRunYear}}` and `{{turningYear}}` per country; `FACT-LOCK.md` lists the numbers, endpoints, causal claims and page pins that an edit must not change.
